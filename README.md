# ChromaKey YCbCr 🔮

Легковесная, независимая от фреймворков JavaScript-библиотека для удаления фона (хромакея) с изображений.

Использует профессиональный алгоритм на основе цветового пространства **YCbCr** (разделение яркости и цветности) и технику **Despill** (удаление цветового ореола), что позволяет получать чистое изображение с сохранением естественных теней и без зеленых бликов на коже.

*   **0 зависимостей:** Работает в браузере и Web Workers.
*   **Высокая точность:** Сохраняет тени и полупрозрачные участки.
*   **Безопасность:** 100% Client-side. Изображения не отправляются на серверы.

## 📦 Подключение

Скачайте файл `chromakey.js` из этого репозитория и положите его в папку с вашим проектом.

```html
<script src="chromakey.js"></script>
```
Либо использовать его как ES-модуль.
```
import { detectBgColor, process } from './chromakey.js';
```
